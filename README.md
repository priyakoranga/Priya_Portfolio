# 💻 Personal Developer Portfolio

A responsive personal portfolio website showcasing my technical skills, projects, learning journey, and interest in building reliable technology solutions.

The portfolio reflects my approach to technology: **understand how systems work, solve problems, and build practical solutions.**

## 🌐 About the Portfolio

The website introduces my background as a Computer Science graduate, highlights my technical interests, and provides a space to explore my projects and connect with me.

### ✨ Features

- **Home:** Introduction and developer profile.
- **About:** Background, interests, and current learning focus.
- **Skills:** Programming, Linux, networking, cloud, DevOps, monitoring, and AI.
- **Projects:** Selected software, infrastructure, and AI projects.
- **Contact:** Contact section with GitHub and LinkedIn links.
- **Responsive Navigation:** Navigation menu designed for different screen sizes.
- **Interactive Elements:** JavaScript-powered functionality.
- **Clean UI:** Modern layout with project cards and technical skill sections.

## 📁 Project Structure

```text
portfolio/
├── index.html
├── portfolio.css
└── portfolio.js
```

- `index.html` — Contains the portfolio sections and page structure.
- `portfolio.css` — Defines the visual design, layout, and responsive styling.
- `portfolio.js` — Handles interactive functionality, such as the navigation menu and dynamic footer year.

## 🚀 Run Locally

### 1. Clone the Repository

```bash
git clone YOUR_PORTFOLIO_REPOSITORY_URL
```

### 2. Open the Project

Open the project folder in Visual Studio Code.

### 3. Run the Website

Open `index.html` directly in your browser, or use the **Live Server** extension in VS Code.

No backend server is required for this static portfolio.
